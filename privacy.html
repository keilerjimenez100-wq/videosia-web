Política de privacidad de VideosIA

Última actualización: 26 de noviembre de 2026.

1. Finalidad de la aplicación

VideosIA es una herramienta de uso personal para crear y subir videos a YouTube mediante YouTube Data API v3.

2. Datos y permisos

La aplicación solicita autorización para subir videos, títulos, descripciones, etiquetas y miniaturas a YouTube.

3. Almacenamiento y seguridad

Las credenciales y los tokens de autorización se almacenan localmente en la computadora del usuario. Los registros contienen identificadores y resultados de las subidas.

4. Uso de los datos

Los datos se utilizan para gestionar las subidas autorizadas a YouTube. No se utilizan para publicidad ni se venden.

5. Revocación y eliminación

El usuario puede retirar el acceso desde la configuración de seguridad de Google:

Administrar permisos de Google

El usuario puede eliminar los tokens y registros locales de la aplicación.
